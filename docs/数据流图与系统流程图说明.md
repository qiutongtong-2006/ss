## 二、数据流图说明

### 2.1 外部实体

| 编号 | 名称 | 说明 |
| --- | --- | --- |
| E1 | 学生 | 系统的主要使用者，提交报修、查询进度、验收评价 |
| E2 | 宿管/管理员 | 受理工单、派单、驳回、维护基础数据、查看统计 |
| E3 | 维修人员 | 接单、填写维修记录、提交完工 |

### 2.2 加工

| 编号 | 名称 | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | 报修提交与进度查询 | 学生的报修信息与照片、楼栋与报修分类、工单状态 | 新工单、工单号与处理进度 |
| 2 | 工单受理与派单 | 待受理工单、受理与派单指令、维修人员清单 | 更新后的工单状态与维修人、派单通知、待受理工单列表 |
| 3 | 维修处理 | 维修人员的接单与维修记录 | 更新后的工单状态、维修记录 |
| 4 | 验收与评价 | 学生的验收结果与评分 | 更新后的工单状态、验收评价记录 |
| 5 | 统计查询与基础数据维护 | 统计查询条件、基础数据维护指令、工单数据 | 统计报表、楼栋与报修分类数据 |

### 2.3 数据存储

| 编号 | 名称 | 主要组成 |
| --- | --- | --- |
| D1 | 用户表 | 学号/工号、姓名、密码、联系方式、角色、楼栋房间 |
| D2 | 报修工单表 | 工单号、报修人、楼栋房间、分类、故障描述、紧急程度、状态、维修人、各节点时间 |
| D3 | 维修过程记录表 | 工单号、操作人、操作类型、说明、时间 |
| D4 | 验收评价表 | 工单号、是否修复、评分、评价内容 |
| D5 | 楼栋与报修分类表 | 楼栋名称、房间号、报修分类、默认工种 |

### 2.4 主要数据流

| 数据流 | 来源 → 去向 | 组成 |
| --- | --- | --- |
| 报修信息与照片 | 学生 → 1 | 楼栋、房间号、报修分类、故障描述、紧急程度、现场照片 |
| 新工单 | 1 → D2 | 工单号、报修人、报修内容、提交时间、状态（待受理） |
| 待受理工单 | D2 → 2 | 状态为"待受理"的工单记录 |
| 维修人员清单 | D1 → 2 | 角色为"维修人员"的用户信息 |
| 更新状态与维修人 | 2 → D2 | 工单状态（已派单）、维修人、派单时间、驳回原因 |
| 派单通知 | 2 → 维修人员 | 工单号、楼栋房间、故障描述、紧急程度 |
| 接单与维修记录 | 维修人员 → 3 | 接单确认、故障原因、处理措施、更换材料 |
| 维修记录 | 3 → D3 | 工单号、操作人、操作类型、说明、时间 |
| 更新工单状态 | 3 → D2 | 工单状态（维修中/待验收）、开工与完工时间 |
| 验收结果与评分 | 学生 → 4 | 是否修复、评分、评价内容、退回原因 |
| 评价记录 | 4 → D4 | 工单号、是否修复、评分、评价内容、评价时间 |
| 统计查询 | D2 → 5 | 指定时间范围内的工单数据 |
| 统计报表 | 5 → 宿管 | 报修总量、分类占比、完成率、维修人员工作量 |
| 楼栋与报修分类 | D5 → 1 | 楼栋名称、房间号、报修分类 |
| 维护楼栋与报修分类 | 5 → D5 | 新增、修改、停用的楼栋与分类记录 |

## 三、系统流程图说明

系统流程图描绘的是物理系统的组成部件与数据在部件间的流动，图中各部件如下：

| 部件 | 符号 | 说明 |
| --- | --- | --- |
| 学生填写报修信息、宿管受理并派单 | 人工操作 | 由人完成的动作 |
| 浏览器报修表单、填写维修记录、提交验收 | 联机输入 | 通过终端录入数据 |
| Django 视图校验并生成工单、更新工单状态与维修人 | 处理 | 系统的加工部件 |
| MySQL 报修工单库 | 联机存储 | 可直接存取的数据库 |
| 宿管端工单池界面、维修人员任务列表、学生端进度与验收 | 显示 | 终端界面输出 |
| 统计报表打印输出 | 文档 | 报表形式的输出 |
| 连接符 A | 连接 | 表示第一行末尾与第二行开头的承接关系 |

图中数据自左向右流动：第一行反映"学生提交—系统建单—写入数据库—宿管受理派单"，经连接符 A 转入第二行"更新工单状态—维修人员接单—学生验收—输出报表"。同一行内的箭头表示数据在部件之间的传递，不表示程序内部的语句顺序。
