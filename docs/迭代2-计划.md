## 三、验收标准

### 宿管端

1. 宿管登录后可以进入工单池，默认显示“待受理”工单。
2. 工单池支持按状态、楼栋、报修分类和关键词筛选。
3. 宿管可以查看工单详情，包括学生联系方式、维修地址、备注和入室授权。
4. 受理时必须选择一名维修人员，提交后状态变为“已派单”。
5. 受理后记录受理时间、派单时间和维修人员。
6. 可以填写联系备注和约定上门时间，保存后在详情页展示。
7. 驳回必须填写原因，状态变为“已驳回”，学生在详情页可见原因。
8. 学生、维修人员和宿管直接输入不属于自己权限的 URL 时被拒绝。

### 学生端

1. 学生可以在“我的报修”中看到自己的全部工单。
2. 列表支持按状态、楼栋和分类筛选。
3. 只有“待受理”工单可以撤销，撤销后状态变为“已撤销”。
4. 学生不能查看、撤销其他学生的工单。
5. 详情页显示处理时间线，至少包含提交、受理/派单、驳回或撤销记录。

## 六、完成的定义

1. 宿管能实际完成一条工单的受理派单和驳回。
2. 学生能查看自己的工单列表并撤销待受理工单。
3. 三种角色直接访问不属于自己的页面时被拒绝。
4. 状态变更、操作人、时间和备注写入状态日志。
5. 数据库迁移已生成并应用，系统检查通过。
6. 迭代结束时完成一次 Git 提交并更新完成记录。
