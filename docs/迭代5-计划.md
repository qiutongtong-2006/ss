## 三、权限矩阵

| 功能 | 学生 | 维修人员 | 宿管 / 超级管理员 |
| --- | --- | --- | --- |
| 学生首页、提交报修、我的报修 | 可用 | 拒绝 | 拒绝 |
| 维修任务列表、接单、填写维修记录 | 拒绝 | 仅本人被派工单 | 拒绝 |
| 工单池、受理、驳回 | 拒绝 | 拒绝 | 可用 |
| 查看工单详情 | 仅本人报修 | 仅本人被派工单 | 全部 |
| 撤销报修、验收、退回、评价 | 仅本人且状态允许 | 拒绝 | 拒绝 |
| 楼栋与报修分类维护 | 拒绝 | 拒绝 | Django Admin |

说明：

1. 超级管理员可进入宿管功能，不冒充学生或维修人员执行业务操作。
2. 未登录用户访问受保护页面时跳转登录页。
3. 已登录但角色或数据范围不符时返回 403，且不得产生数据变更。

## 四、验收标准

### 三角色权限

1. 所有列表页、详情页和状态操作均先校验登录状态与角色。
2. 学生不能查看、操作其他学生的工单。
3. 维修人员不能查看、接取或完工未派给自己的工单。
4. 宿管可查看全部工单并受理、驳回；不能代替学生验收或维修人员完工。
5. 直接输入 URL、修改请求参数或提交越权表单，执行结果与页面隐藏一致。
6. 所有写操作仍校验工单状态；越权或非法请求不新增日志、评价或维修记录。

### 楼栋与报修分类

1. 超级管理员可在 Django Admin 新增、修改、启用和停用楼栋及报修分类。
2. 学生提交报修时只能选择已启用的楼栋和分类，不能自行创建基础数据。
3. 已停用的基础数据保留在历史工单和筛选条件中，但不出现在新报修选项中。
4. 被工单引用的楼栋或分类禁止删除；未被引用的数据允许删除。
