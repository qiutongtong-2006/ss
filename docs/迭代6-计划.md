## 三、验收标准

### D1 工单号并发安全

1. 每个业务日期使用独立序号记录。
2. 生成序号时锁定当天记录并在事务内递增。
3. 首次生成序号时可从已有工单号继续，不重复历史编号。
4. 多线程同时提交报修，全部成功且工单号唯一。

### D2 待受理状态竞争

1. 受理、驳回和撤销都在事务内锁定工单并重新检查状态。
2. 并发请求以先取得锁的合法操作为准。
3. 竞争失败的一方不再写入状态、原因或日志。
4. 每个工单最终只能产生一条对应的状态变更日志。

### D3 重复报修提醒

1. 同一楼栋、房间和分类存在待受理、已派单、维修中或待验收工单时显示提醒。
2. 首次提交只提示，不自动创建工单。
3. 用户确认不是同一问题后可以继续提交。
4. 已完成、已驳回和已撤销工单不算未完成任务。

### D4 异常角色拦截

1. 角色不在学生、维修人员、宿管三种有效值内的账号不能登录前台。
2. 已存在的异常角色会话访问首页时被退出并跳转登录页。
3. 模型校验拒绝无效角色，避免通过后台表单继续写入异常配置。

### C1 统计报表

1. 宿管和超级管理员可以访问，学生与维修人员返回 403。
2. 支持今天、最近 7 天、最近 30 天和全部时间范围。
3. 报修总量、已完成数量、处理中数量和完成率口径明确。
4. 分类占比支持表格和不依赖外部脚本的饼图，停用分类的历史工单仍参与统计。
5. 无数据时不发生除零错误，并显示空状态。
