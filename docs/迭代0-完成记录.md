## 三、版本调整说明

最初安装的是 Django 6.1.2，但连接数据库时报错：

```text
MySQL 8.4 or later is required (found 8.0.45)
```

Django 6.1 要求 MySQL 8.4 及以上，本机 MySQL 为 8.0.45。为不影响原有数据库和其他项目，选择将 Django 降为 5.2 LTS，而不是升级 MySQL。Django 5.2 是长期支持版本，与 MySQL 8.0 兼容，适合本课程项目。
